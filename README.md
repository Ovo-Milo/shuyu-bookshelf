# 书屿（Shuyu Bookshelf）

一个用于收藏、整理和回顾个人阅读记录的在线书架。

在线访问：[milobookshelf.cloud](https://milobookshelf.cloud)

## 项目简介

书屿希望把“想读、在读、读完”的书安静地收在一个地方。你可以搜索书籍、查看封面和出版信息，将书加入自己的书架，并记录评分、阅读日期与简短笔记。

当前版本无需注册。阅读记录保存在浏览器本地，适合作为个人使用的轻量阅读档案。

## 主要功能

- 按书名、作者或 ISBN 搜索公开书目
- 显示书名、作者、出版社、出版年份和封面
- 手动添加没有搜索到的书籍
- 将书籍标记为“想读”“在读”或“读完”
- 记录 1–5 星评分、开始日期、读完日期和阅读笔记
- 按阅读状态筛选书架
- 按最近更新、评分或书名排序
- 在个人书架内快速搜索
- 数据自动保存在当前浏览器的 localStorage
- 支持桌面端和移动端页面

## 技术栈

- Next.js 16
- React 19
- TypeScript
- vinext / Vite
- Tailwind CSS 4 与自定义样式
- Open Library 书目与封面接口
- Docker + Caddy（线上部署）

## 本地运行

环境要求：Node.js >= 22.13.0

```bash
npm install
npm run dev
```

构建并启动生产版本：

```bash
npm run build
npm run start
```

代码检查与测试：

```bash
npm run lint
npm test
```

## 数据与隐私

书架、评分和笔记目前只保存在使用者当前浏览器中，不会自动同步到服务器或其他设备。清除浏览器网站数据可能会删除这些记录。

项目暂时没有用户账户和云端数据库。后续如需多设备同步，可增加登录系统和数据库存储。

## 书籍搜索说明

当前书籍搜索与封面使用 Open Library。部分中国大陆网络或云服务器可能无法稳定访问该服务，导致搜索超时或封面无法显示。后续可以接入可在国内稳定访问的书目服务，或增加代理、缓存与多数据源回退。

## 部署与更新

线上站点运行在 Ubuntu 服务器上，由 Docker 承载应用，Caddy 提供 HTTPS 和反向代理。

修改代码后的常规流程：

1. 在本地完成修改并测试。
2. 提交并推送到 GitHub。
3. 在服务器拉取最新代码。
4. 重新构建并启动 Docker 容器。

仅修改网页代码时不需要重新购买或安装 Docker，但需要重新构建应用镜像，服务器上的 Caddy 和域名配置通常无需改动。
